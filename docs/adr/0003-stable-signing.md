# ADR-0003: подпись сертификатом Apple Development

Статус: Accepted · Дата: 2026-10-28

## Контекст
macOS 15 привязывает разрешение «Локальная сеть» к подписи приложения. Сборки подписывались ad‑hoc (`CODE_SIGN_IDENTITY = "-"`), у каждой пересборки новая подпись, и после переустановки в `/Applications` разрешение пропадало. Сервер `adb`, которого запускает приложение, получал `No route to host`, хотя ТВ был доступен (пинг и TCP 5555 проходят).

## Решение
Подписывать сертификатом `Apple Development` команды `FB52TKY2U5` (из связки ключей пользователя) в ручном режиме, без профиля: для приложения без песочницы и entitlements он не нужен.

## Последствия
- Разрешение «Локальная сеть» выдаётся один раз.
- На чужом Mac нужно поменять `DEVELOPMENT_TEAM` в `project.yml` (или вернуть `-`).
