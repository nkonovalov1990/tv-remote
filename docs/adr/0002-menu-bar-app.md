# ADR-0002: пульт в строке меню (MenuBarExtra)

Статус: Accepted · Дата: 2026-10-28

## Контекст
Пульт нужен «на секунду»: поставить на паузу, сделать тише. Обычное окно теряется за другими окнами, его надо искать.

## Решение
`MenuBarExtra` со стилем `.window` и `LSUIElement = YES` (нет иконки в Dock). Обычное окно `WindowGroup` убираем. Решение пользователя от 2026-10-28.

## Последствия
- Нужен явный пункт «Выйти» — иначе приложение не закрыть.
- Окно‑поповер закрывается при потере фокуса; клавиатура работает, пока оно открыто.
- Автоподключение при открытии (R10), потому что после перезагрузки Mac сервер adb теряет соединение.
