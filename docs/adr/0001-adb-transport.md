# ADR-0001: ADB как транспорт управления ТВ

Статус: Accepted · Дата: 2026-10-28

## Контекст
Android TV можно управлять по сети двумя способами:
1. **ADB** (порт 5555): `input keyevent` поддерживает все коды клавиш Android. Нужен включённый режим разработчика на ТВ и бинарник `adb` на Mac.
2. **Android TV Remote v2** (порты 6466/6467): TLS с клиентским сертификатом, пейринг по PIN, protobuf. На ТВ ничего включать не нужно.

## Решение
ADB через внешний бинарник `adb`, вызов через `Process`. Выбрано пользователем 2026-10-28.

## Почему
- Кода в разы меньше: ни TLS, ни генерации X.509, ни protobuf.
- `adb` уже установлен (`/opt/homebrew/bin/adb`).
- Полный набор клавиш, а не только те, что есть в Remote v2.

## Последствия
- Один раз включить на ТВ «Отладку по сети» и разрешить подключение Mac.
- App Sandbox выключен: песочнице нельзя запускать `adb` из Homebrew. Значит, без App Store.
- Каждое нажатие — новый процесс `adb shell` (~100–200 мс). Если задержка будет мешать — держать постоянную сессию `adb shell`.
- Путь к `adb` ищем по известным местам: у GUI-приложений нет PATH из Homebrew.
