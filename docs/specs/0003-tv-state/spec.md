# SPEC-0003: состояние телевизора в пульте

Статус: Approved · Дата: 2026-10-28 · Поправляет «Вне рамок» в SPEC-0002: громкость и воспроизведение ADB всё-таки сообщает.

## Зачем
Пульт работал «вслепую»: не видно, включён ли ТВ, что открыто, какая громкость и играет ли что-нибудь. Пользователь выбрал четыре показателя: питание, текущее приложение, громкость, что играет.

## Как читаем
Один вызов `adb -s <ip>:5555 shell "<4 команды>"` (~0.4 с на TCL Smart TV Pro, Android 12):
- `dumpsys power | grep -m1 mWakefulness=` → `Awake` / `Asleep` / `Dreaming`;
- `dumpsys window | grep -m1 mCurrentFocus` → пакет приложения на переднем плане;
- `cmd media_session volume --stream 3 --get` → `volume is N in range [0..M]`;
- `dumpsys media_session | grep -E 'package=|state=PlaybackState|metadata:'` → сессии; берём первую в состоянии 3 (играет) или 2 (пауза), название — первое поле `description=`.

Шум вроде `Broken pipe` (из‑за `grep -m1`) и `error=` внутри PlaybackState — не ошибка.
Реальный вывод: `TVRemoteTests/Fixtures/state-home.txt`; синтетические (формат Android, на ТВ ещё не сверены): `state-playing-synthetic.txt`, `state-asleep-synthetic.txt`.

## Требования
| ID | Требование | Проверка |
|----|-----------|----------|
| R13 | Питание: точка в шапке зелёная — ТВ включён, серая — спит, оранжевая — нет связи. | `TVStateTests`, вручную |
| R14 | Текущее приложение: в шапке вместо IP — имя приложения («Главный экран», «YouTube», «Netflix», …; неизвестное — имя пакета). IP остаётся в настройках. | `TVStateTests` |
| R15 | Громкость: число между кнопками −/+ на вкладке «Медиа» («22»). | `TVStateTests`, вручную |
| R16 | Что играет: над play/pause — название (одна строка, обрезка с многоточием); иконка play/pause по состоянию: играет → `pause.fill`, пауза → `play.fill`, неизвестно → `playpause.fill`. | `TVStateTests`, вручную |
| R17 | Опрос раз в 2 с, только пока пульт открыт и ТВ подключён; сразу после нажатия — внеочередное обновление. Ошибка опроса не трогает статус подключения и не мешает нажатиям. | `RemoteModelTests` |

## Вне рамок
Mute (неясно, к какому потоку относится `Muted:` на TCL), обложка, позиция/длительность, настоящие названия всех приложений (нужен разбор APK).
