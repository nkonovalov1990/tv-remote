# SPEC-0002: интерфейс по скетчу и приложение в строке меню

Статус: Approved · Дата: 2026-10-28 · Заменяет в SPEC-0001: R4, R5 (интерфейс). R1–R3, R6, R7 без изменений.

## Зачем
Первый интерфейс был «всё на одном экране» с мелкими кнопками. Пользователь нарисовал скетч: в первую очередь нужны крупные play/pause и громкость, крестовина — на отдельной вкладке. Пульт должен быть всегда под рукой, поэтому живёт в строке меню, а не в обычном окне.

Источник: скетч пользователя и правленый им HTML-прототип ([копия](../../design/prototype-v2.dc.html), [холст](https://claude.ai/artifact/15hMf762xitbKV87aXhH1m)).

## Требования
| ID | Требование | Было | Проверка |
|----|-----------|------|----------|
| R4′ | Кнопки: play/pause, громкость −/+, D‑pad + OK, питание, домой, назад. Mute, перемотка, источник сигнала и настройки убраны (прототип v2). | R4: 16 кнопок | `ADBTests` (коды), вручную |
| R5′ | Клавиатура: стрелки → D‑pad, Return → OK, Esc/Delete → назад, пробел → play/pause. Не срабатывает при вводе IP. | R5 без пробела | вручную |
| R8 | Приложение живёт только в строке меню (иконка `tv`), без иконки в Dock; клик открывает окно‑пульт 340pt. Есть «Выйти». | — | вручную |
| R9 | Сверху сегмент «Медиа / Навигация». Медиа: play/pause (акцентная заливка) и громкость (две половины одной «пилюли») делят высоту поровну. Навигация: квадратная крестовина из четырёх секторов‑трапеций, OK — белый квадрат на 25% площади в центре (правка T13); нажимается только видимый сектор. Нижняя панель (питание, домой, назад) общая для обеих вкладок. Последняя вкладка запоминается. | — | `RemoteModelTests` (вкладка), вручную |
| R10 | Подключение спрятано: в шапке точка статуса + имя/IP и кнопка настроек, которая раскрывает поле IP, найденные ТВ и «Подключить». Пока IP не задан, настройки раскрыты сами. При открытии пульта с сохранённым IP подключение запускается автоматически. | R1–R3 на главном экране | `RemoteModelTests` (`connectIfSaved`), вручную |

## Вне рамок
Глобальные горячие клавиши, отображение громкости (ADB её не сообщает), иконка play/pause по состоянию воспроизведения (ADB его не сообщает).

## Дополнение 2026-10-28
| ID | Требование | Проверка |
|----|-----------|----------|
| R11 | Если macOS блокирует локальную сеть (`adb` отвечает «No route to host»), статус говорит, что делать: «macOS блокирует локальную сеть: Настройки → Конфиденциальность и безопасность → Локальная сеть → включите TV Remote». И при подключении, и при нажатии. Почему: на живом ТВ пользователь видел только «No route to host» при доступном ТВ. | `RemoteModelTests` |
| R12 | Разрешение «Локальная сеть» переживает пересборку: сборка подписана стабильной подписью ([ADR-0003](../../adr/0003-stable-signing.md)). | вручную: `codesign -dv` |
| R18 | Самолечение: если `adb connect` отвечает «No route to host», приложение выполняет `adb kill-server` и повторяет подключение один раз. Почему: фоновый сервер adb переживает приложение; когда запустивший его экземпляр закрыт (переустановка, «Выйти»), macOS лишает осиротевший сервер локальной сети, а новые запуски подхватывают этот сервер. Подтверждено на живом ТВ 2026-10-28: старый сервер — «No route to host», сервер от текущего приложения — `device`. Минус: перезапуск сервера рвёт чужие adb-сессии в терминале. | `ADBTests` |
| R19 | Когда показана подсказка про локальную сеть, рядом кнопка «Открыть настройки», которая открывает Настройки → Конфиденциальность → Локальная сеть. | вручную |
