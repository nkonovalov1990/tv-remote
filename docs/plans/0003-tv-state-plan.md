# PLAN-0003: реализация SPEC-0003

1. T21 `TVState` — чистый парсер вывода по фикстурам (TDD): `awake: Bool?`, `app: String?` (пакет), `appName` (словарь + фолбэк), `volume: Int?`, `title: String?`, `playing: Bool?`.
2. T22 `ADB.state(host:)` — один `shell` с 4 командами → `TVState`; не применять правило «есть "error" → ошибка» из `press` (TDD на `Fake`).
3. T23 `RemoteModel`: `tv: TVState?`, `refresh()`, обновление после `press` (TDD).
4. T24 UI: точка питания, имя приложения, громкость в «пилюле», название и иконка play/pause; цикл опроса в `.task` поповера (отменяется при закрытии).
5. T25 Проверка: тесты, офскрин‑рендер, переустановка, сверка с живым ТВ.
